## 醫事放射模擬系統（擬真競賽訓練用）

直接用瀏覽器開啟 `index.html` 即可使用（單一檔案、不需網路）。重新整理頁面即重設所有資料。所有病人與檢驗資料皆為虛構。

- **電腦斷層掃描系統**：今日工作清單 → 選取檢查 → 完成檢查前核對 → 設定參數 → 開始掃描；完成後影像自動傳送至 PACS。可暫停檢查（須填寫原因），下方有操作紀錄供教練檢討。
- **PACS 影像系統**：以病歷號／姓名／檢查單號查詢，開啟合成 CT 影像；支援視窗預設、拖曳調整 W/L、滾輪換切面、反相、縮放、游標顯示 HU 值。
- **檢驗報告查詢系統**：以病歷號或姓名查詢，異常值以 H/L 標示。
